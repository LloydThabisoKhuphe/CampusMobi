GETTING STARTED
================================================================================

1. EXTRACT
   unzip nodejs-backend.zip
   cd nodejs-backend

2. INSTALL
   npm install

3. CONFIGURE
   cp .env.example .env
   (no changes needed - ready for local dev)

4. RUN
   npm run dev

5. TEST
   curl http://localhost:8080/api/auth/guest

✅ That's it! API is running on http://localhost:8080/api

================================================================================
API ENDPOINTS (15 TOTAL)
================================================================================

PUBLIC ENDPOINTS:
  POST   /auth/register           → Create account
  POST   /auth/login              → Login
  POST   /auth/guest              → Guest login
  POST   /auth/forgot-password    → Password reset
  GET    /services                → Campus services
  GET    /map/locations           → Campus locations

PROTECTED ENDPOINTS (require JWT token):
  GET    /wallet                  → Get wallet info
  POST   /wallet/topup            → Add money
  POST   /wallet/pay              → Make payment
  GET    /calendar/events         → View events
  POST   /calendar/events         → Create event
  DELETE /calendar/events/:id     → Delete event
  GET    /notifications           → View notifications
  PATCH  /notifications/:id/read  → Mark as read
  GET    /card                    → Get student card

PRODUCTION DEPLOYMENT
================================================================================

For production, update .env:

NODE_ENV=production
JWT_SECRET=your-strong-random-32-char-key
DB_URL=postgresql://user:password@host:5432/campusmobi
CORS_ALLOWED_ORIGINS=https://yourdomain.com

Then deploy using:
- Docker container
- VM with Node.js
- Serverless platform (Vercel, Netlify)
- Traditional server with PM2

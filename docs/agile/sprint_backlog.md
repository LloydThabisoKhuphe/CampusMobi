# User Stories

## Authentication

1. As a student, I want to create a account so that I can access uniersity services.
2. As a student, I want to log out so that I can protect my account from unauthorized access.

---

## Dashboard

3. As a student, I want to view a dashboard so that I can quickly access all features of the system.
4. As a student, I want to see my schedule and notifications so that I stay organised.

---

## Virtual Student Card

5. As a student, I want to view my virtual student card so that I can Access the study ,library ,entrance and etc..
6. As a student, I want my student card to display my details clearly so that it can be used for verification.

---

## Wallet System

7. As a student, I want to load money into my wallet so that I can pay for campus services.
8. As a student, I want to view my wallet balance so that I know how much money I have available.
9. As a student, I want to make payments using my wallet so that I can pay easily without cash.

---

## Printing Feature

10. As a student, I want to upload documents so that I can print them at the campus library.
11. As a student, I want to receive a confirmation or PIN after uploading so that I can collect my printed documents.
12. As a student, I want the system to link my account with the printing service so that the process is seamless.

---

## Campus Map

13. As a student, I want to view a campus map so that I can navigate around the campus easily.
14. As a student, I want to search for locations on the map so that I can find specific places quickly.
15. As a student, I want to see important locations like the library and cafeteria so that I can access services easily.

---

## Notifications

17. As a student, I want to receive notifications so for my schedule and also Updates from other students such reporting missing student card.

---

## System Quality

18. As a student, I want the system to be fast and responsive so that I can use it without delays.
19. As a student, I want the system to be secure so that my personal and financial information is protected.
20. As a student, I want the system to be easy to use so that I can navigate it without confusion.

# User Stories

## Authentication

1. As a student, I want to create an account so that I can access the system.

2. As a student, I want to log in so that I can securely access my dashboard.

3. As a student, I want to log out so that I can protect my account.
---

## Dashboard

4. As a student, I want to view a dashboard so that I can access all features easily.

5. As a student, I want to see my schedule and notifications so that I stay organized.

---

## Virtual Student Card

6. As a student, I want to view my virtual student card so that I can identify myself when needed.

7. As a student, I want my student card to display my details clearly for verification.

---

## Calendar System

8. As a student, I want to view my calendar so that I can track my classes and events.

9. As a student, I want to add events to my calendar so that I can manage my schedule.

---

## Campus Map

10. As a student, I want to view a campus map so that I can navigate around the campus easily.

11. As a student, I want to search for locations on the map so that i can find specific places quickly.

12. As a student, I want to see important places like the library and admin offices so that I can access services easily.

--- 

## Notifications

13. As a student, I want to receive reminders for upcoming events so that I don’t miss classes.

14. As a student, I want to see notifications on my dashboard so that I stay updated.

---

## Wallet (Demo)

15. As a student, I want to view a wallet balance so that I can see my available funds.

16. As a student, I want to simulate adding money so that I can test the system.
---

## System Quality

17. As a student, I want the system to be fast and responsive so that I can use it without delays.

18. As a student, I want the system to be secure so that my personal and financial information is protected. 

19. As a student, I want the system to be easy to use so that I can navigate it without confusion.

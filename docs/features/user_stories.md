# User Stories for CampusMobi


## Authentication & Virtual Student Card
As a student, I want to log in using my student number or email address so that I can securely access CampusMobi.
As a student, I want to view my digital student card so that I do not need to carry my physical student card everywhere.
As a student, I want my digital card to display my personal details and QR code so that I can identify myself on campus when needed.
As campus staff, I want to scan a student’s QR code so that I can quickly verify the student’s identity.


## Calendar & Scheduling
As a student, I want to view my academic schedule on a calendar so that I can keep track of my classes and activities.
As a student, I want to add events to my calendar so that I can organize my academic and personal activities.
As a student, I want to edit or remove events from my calendar so that I can keep my schedule updated.
As a student, I want to see upcoming events for the day so that I can manage my time effectively.


## Notifications
As a student, I want to receive notifications before classes or events so that I do not miss important activities.
As a student, I want automatic reminders linked to my calendar events so that I can stay informed without checking the calendar all the time.
As a student, I want notifications to appear clearly on the platform so that I can quickly read important updates.

## Campus Map & Navigation
As a student, I want to view a campus map so that I can easily navigate around campus.
As a student, I want to search for lecture halls, labs, residences, cafeterias, and offices so that I can find locations quickly.
As a student, I want to click on campus buildings to see information about them so that I can better understand campus facilities.
As a new student, I want to use the map to locate residences and lecture venues so that I can avoid getting lost.


## Wallet System (Demo)
As a student, I want to simulate adding funds to my wallet so that I can understand how a digital campus payment system would work.
As a student, I want to simulate making transactions using the wallet so that I can experience a digital payment process.
As a student, I want to view my wallet balance so that I can track my simulated spending.


## General System Features
As a student, I want all campus services in one platform so that I do not need to use multiple disconnected systems.
As a student, I want the system to be simple and user-friendly so that I can easily use the platform every day.
As campus administration, I want to monitor student engagement with CampusMobi so that we can evaluate how useful the platform is.
As campus administration, I want to collect feedback from users so that the platform can be improved over time.

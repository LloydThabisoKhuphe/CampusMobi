# CampusMobi - Features  

## Features List

### Must Have Features
- Student login and authentication system
- Digital student card with QR code
- QR code scanning for student verification
- Academic calendar and schedule management
- Add, edit, and delete calendar events
- Upcoming events and daily schedule view
- Notification and reminder system
- Interactive campus map and navigation
- Search for lecture halls, labs, residences, cafeterias, and offices
- Wallet balance and simulated transaction system
- User-friendly interface integrating all campus services

### Should Have Features
- Automatic reminders linked to calendar events
- Detailed campus building information pages
- Real-time notification display
- Student engagement monitoring dashboard for administration
- Feedback collection and reporting system
- Personalized student dashboard

### Could Have Features
- Smart navigation assistance for new students
- Transaction history for wallet activities
- Customizable notification preferences
- Event recommendations based on student schedules
- Campus announcements and news feed
- Dark mode and accessibility settings

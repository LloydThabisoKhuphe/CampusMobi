## 4.	Project Management Approach

The team will follow a simple Agile approach:
-	Work will be divided into small tasks (sprints)
-	Weekly meetings will be held to track progress
-	Tasks will be assigned and reviewed regularly
-	GitHub will be used to track progress, contributions and version control
- Changes are incorporated based on team feedback and progress

## 5.	Risk Management
```
The following risks have been identified along with solutions strategies:

•	 Risk: Team members not contributing
Solution: Weekly meetings, task assignment, and monitoring GitHub activity

•	 Risk: Technical challenges during development
Solution: Simplify system features and seek help early

•	 Risk: Missing deadlines
Solution: Set internal deadlines before official due dates

•	 Risk: Poor communication within the team
Solution: Use WhatsApp or Microsoft Teams for continuous communication

•	 Risk: Loss of project files or errors in code
Solution: Use GitHub for version control and backups
```

## 8. Project Management Approach

During development, the project scope was refined to better match time constraints and ensure successful delivery of a working system.

### Initial Plan

The system originally included:

- Printing services integration
- Cafeteria pre-order functionality
- Real payment processing

### Changes Made

To reduce complexity and focus on core functionality:

- Printing and cafeteria features were removed
- Real payment integration was replaced with a demo wallet system
- A calendar system was introduced as a core feature
- Schedule-based notifications were added to improve usability

### Final MVP Focus

The system now focuses on:

- User authentication
- Virtual student card (mocked)
- Calendar and schedule management
- Notifications based on events
- Campus navigation
- Wallet (demo)

These changes ensured that the system remained achievable while still delivering meaningful value to users.

## 9.	Conclusion 

This management plan provides a structured approach to developing the Campus-Mobi system. By clearly defining roles, timelines, risks, and technologies, the team will be able to work efficiently, collaborate effectively, and successfully deliver the project within the given timeframe.

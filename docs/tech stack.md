# Technology Stack  

- Backend: Spring Boot (Java)  
- Frontend: React.js (HTML, CSS, JavaScript)  
- Database: MySQL  

## Justification  

- Spring Boot: Enables rapid backend development with built-in support for RESTful APIs, security (Spring Security), and a scalable architecture suitable for handling student authentication and campus services.  

- React: Supports reusable UI components and fast rendering using JavaScript, while HTML (via JSX) structures the interface and CSS ensures responsive and user-friendly design.  

- MySQL: Reliable relational database for managing structured data such as student profiles, schedules, and events, with strong integration support for Spring Boot.
